# BeyondLimits — Product Specification

## Core Purpose

**BeyondLimits** is a strict self-control, fitness, and habit accountability platform designed for radical accountability rather than passive tracking.

### The Problem It Solves

Traditional habit trackers allow users to:
- Check boxes without reflection
- Quietly abandon streaks when relapses occur
- Skip understanding their cognitive triggers
- Lack physical outlets for dopamine cravings

**BeyondLimits enforces radical accountability** by making reflection mandatory, integrating physical fitness, and providing duo-based competitive accountability.

---

## Target Users

- **Primary Users**: Accountability duos (Bharath CD & Bharath R)
- **User Profile**: Individuals seeking to eliminate compulsive habits through strict daily tracking, mandatory reflection, and physical discipline
- **Use Case**: Building unbreakable self-control through daily attendance logging, relapse analysis, and guided workouts

---

## Core Features

### 1. Strict Daily Attendance Tracking

**Purpose**: Track daily self-control state with zero tolerance for passive logging.

**Behavior**:
- Each day can be marked as either **Clean** (self-controlled) or **Relapsed**
- Users can update past records inline in the dashboard table
- Records include date, status, reason/notes, trigger category, emotional state, and urge intensity

### 2. Mandatory Relapse Reflection

**Purpose**: Prevent passive checkbox ticking by requiring detailed analysis when marking a relapse.

**Rules**:
- **Minimum 3 characters** required for reflection text when marking a relapse
- User must select:
  - **Trigger Category**: Late Night Phone Use, Academic Stress, Boredom, Social Media, or Other
  - **Emotional State**: Focused, Restless, Anxious, Lethargic, or Other
  - **Urge Intensity**: Scale from 1 (weak) to 10 (overwhelming)
- Reflection text must explain:
  - Why the relapse happened
  - What triggered it
  - How to prevent it next time

**Validation**: The system will not accept a relapse log without all required fields populated.

### 3. Guided 12-Exercise Workout Suite

**Purpose**: Provide a physical outlet for dopamine cravings and build mental-physical discipline.

**Exercises** (in order):
1. Jumping Jacks
2. Squats
3. Pushups
4. Lunges
5. Planks
6. Mountain Climbers
7. Burpees
8. High Knees
9. Bicycle Crunches
10. Wall Sits
11. Glute Bridges
12. Tricep Dips

**Workout Flow**:
- **Voice Guidance**: Web Speech API Text-to-Speech announces each exercise
- **Timers**: 60-second high-intensity exercise intervals
- **Rest Periods**: 30-second rest between exercises
- **Rest Controls**:
  - `+10s` button to extend rest when exhausted
  - `Skip` button to jump directly to next exercise
- **Visual Guides**: High-resolution exercise images with modal popups for form cues and safety tips
- **Completion**: Audio fanfare and celebratory stat cards upon completing all 12 exercises

### 4. Analytics & Streaks

**Statistics Tracked**:
- **Login Streaks**: Consecutive days with app access
- **Clean Streaks**: Consecutive days of self-control (no relapses)
- **Workout Streaks**: Consecutive days with completed workouts
- **All-Time Records**: Longest streaks ever achieved

**Analytics**:
- Weekly discipline rate (% of clean days)
- Monthly discipline rate
- Clean-to-relapse ratio
- Trigger category breakdown distribution
- Emotional state patterns
- Average urge intensity trends

### 5. Duo Accountability & Competitive Leaderboards

**Purpose**: Create accountability through peer comparison and healthy competition.

**Features**:
- Weekly discipline comparison between partners
- Side-by-side streak tracking
- Challenge leaderboards (7-Day Workout Blitz, 14-Day Clean Sprint, etc.)
- Visual leader badges and victory indicators

### 6. Daily AI Motivation

**Purpose**: Provide fresh daily focus themes and neuroscience-backed insights.

**Content Generated**:
- Daily focus theme
- Actionable habit suggestion
- Philosophical quote with attribution
- Neuroscience insight (with live web research citations via Tavily)
- Generated by Gemini AI

### 7. Automated Daily Reminders

**Channels**:
- **Mobile Push Notifications**: Via ntfy.sh
- **SMS**: Via Twilio (optional)

**Schedule**:
- Daily at 8:00 PM (configurable timezone)
- Prompts users to mark their daily attendance before midnight

## User Interface Principles

### Authentication Pages
- **Clean White Theme**: High-contrast white cards (`bg-white`) on slate background (`bg-slate-50`)
- **Typography**: Slate & emerald high-contrast color scheme
- **No Circular Clipping**: Rectangular, professional authentication layout
- **Multi-Strategy Support**: Email+Password, Google OAuth, Password Reset

### Dashboard
- **Inline Editable Table**: Users can click and edit past attendance records directly
- **Real-Time Updates**: Changes sync immediately with Supabase
- **Responsive Design**: Mobile-first, works on iOS, Android, and desktop
- **Progressive Web App (PWA)**: Fully installable with offline support

---

## Data Privacy & Security

### Authentication
- **Zero-Bypass**: All routes protected by Clerk Edge Middleware
- **Multi-Device Support**: Sessions synchronized across devices
- **Secure Token Storage**: HTTP-only cookies and JWT tokens

### User Data Scope
- **All database queries MUST be scoped by user ID**
- Row-Level Security (RLS) enforced at Supabase level
- No cross-user data leakage

### Personal Reflections
- Relapse reflections are private and only visible to the authenticated user
- Accountability partners can see statistics but NOT detailed reflection text (future feature consideration)

---

## Gamification Elements

### Challenges
- **7-Day Workout Blitz**: Complete 7 consecutive daily workouts
- **14-Day Clean Sprint**: Maintain 14 consecutive clean days
- **30-Day Login Warrior**: Log in every day for 30 days
- **XP Rewards**: Points awarded for challenge completion

### Badges
- **Tiers**: Bronze, Silver, Gold, Diamond
- **Unlock Conditions**: Based on streak milestones and challenge completions
- **Visual Representation**: Badge icons displayed in user profile

### Streak Freeze
- **Purpose**: Allow occasional missed days without breaking streaks
- **Default**: 1 streak freeze available per user
- **Usage**: Automatically consumed when a login is missed

- **Local Development**: JSON/SQLite fallback for offline development
- **Production**: Supabase PostgreSQL with RLS and automated triggers

### Performance Requirements
- Dashboard must load within 2 seconds on 4G connection
- Real-time updates on attendance edits
- Workout timer accuracy within 100ms

### Accessibility
- Keyboard navigation support
- Screen reader compatibility
- High contrast mode support

### Progressive Web App
- Installable on all platforms (iOS, Android, macOS, Windows)
- Offline support for viewing historical data
- Custom app icons and splash screens

## Design Philosophy

**BeyondLimits is not a gentle habit tracker.**

It is a strict accountability system that:
- Refuses to let relapses slide without reflection
- Forces confrontation with cognitive triggers
- Integrates physical discipline as a core feature
- Creates peer pressure through competitive leaderboards
- Eliminates excuses through mandatory daily logging

The app's tone is **firm, motivational, and unapologetic**. It treats users as warriors building mental fortitude, not patients needing coddling.
